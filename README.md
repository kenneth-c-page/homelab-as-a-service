# homelab-as-a-service

Group project for OS security class.

# Idea

Plug and play homelab services

# Services

- Plex/JellyFin server
- Music streaming server
- SearXNG
- PiHole/AdGuard/Unbound
- Immich
- OpenOffice/collaboration
- NextCloud file storage
- VaultWarden
- 2FA (Authentik)
- ProtonMail bridge
- Matrix?
- HeadScale (port forwarded?)
- Web server

# Extensions
- Terraform pve provisioning
- Web UI
- OS Image verifier
