# homelab-as-a-service

Group project for OS security class.

# Idea

Plug and play homelab services

- Music streaming server: navidrome
- SearXNG
- PiHole/AdGuard/Unbound
- Immich
- OpenOffice/collaboration

- VaultWarden
- 2FA (Authentik)
- Matrix?
